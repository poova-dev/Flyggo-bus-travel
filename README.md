# Flyggo Bus Travel 🚌

Tamil Nadu's No.1 Online Bus Ticket Booking Platform. Rebuilt with a modern RedBus-inspired design (white/red color patterns) and optimized for regional transit routes.

## 🚀 Features
* **Home Page:** Search form, dynamic marquee, popular routes, and traveller reviews.
* **Booking Engine:** Interactive 2+1 Sleeper and 2+2 Seater seat layout maps, advanced filters (timing, bus type, amenities), and passenger info verification.
* **Gallery:** Masonry photo gallery with category filters and Cloudinary uploads.
* **Admin Dashboard:** Stats overview (revenue, trips, users) with bookings/moderation tables.
* **Firebase Backend:** Auth, Cloud Firestore database configuration, and security rules.

## 🛠 Setup & Run
1. Serve the project files locally using any server (e.g. `npx http-server`).
2. Open `admin/seed.html` in your browser to seed sample data into Firestore database.
3. Start booking buses at `index.html`!
